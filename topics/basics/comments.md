# Comments

**Date started:** 2026-10-17
**Status:** Learning

## What it is
Comments are notes in the code that JavaScript ignores. They explain what the code is doing, for yourself or for other people reading it.

## Syntax
```javascript
// Single-line comment: everything after // is ignored

/*
  Multi-line comment:
  everything between these markers is ignored
*/

console.log("This runs"); // comments can go at the end of a line too
```

## Key rules and gotchas
- Write comments to explain *why* or *what* something is for, not to repeat the code.
- Commented-out code doesn't run, which is handy for testing without deleting code.
- `/* */` can't be nested inside another `/* */` block.
