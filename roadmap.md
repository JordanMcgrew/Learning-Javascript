# JavaScript Roadmap

The full path from first lines of code to building real programs. Work top to bottom. Codecademy's course covers the early phases, and later phases may need other resources. Each topic gets a note in `topics/` when I learn it.

**Understanding levels:**
- **Seen:** I've been introduced to it.
- **Learning:** I'm working through it and can use it with notes.
- **Practiced:** I can use it on my own without looking things up.
- **Explain:** I can teach it back in my own words and predict its behavior.

---

## Phase 1: Foundations
- [ ] Running JavaScript and `console.log()`
- [ ] Comments (`//` and `/* */`)
- [ ] Data types: numbers, strings, booleans, `undefined`, `null`
- [ ] Variables: `let`, `const`, and `var` (in progress)
- [ ] Arithmetic operators and operator precedence
- [ ] String concatenation and template literals
- [ ] Properties (`.length`) and the dot operator
- [ ] Methods and how data types provide them

## Phase 2: Making decisions
- [ ] Comparison operators (`===`, `!==`, `<`, `>`) and why `===` is preferred
- [ ] Logical operators (`&&`, `||`, `!`)
- [ ] Truthy and falsy values
- [ ] `if`, `else if`, and `else`
- [ ] `switch` statements
- [ ] Ternary operator

## Phase 3: Repeating work
- [ ] `while` and `do...while` loops
- [ ] `for` loops
- [ ] `break` and `continue`
- [ ] Nested loops

## Phase 4: Functions
- [ ] Declaring and calling functions
- [ ] Parameters and return values
- [ ] Function expressions and arrow functions
- [ ] Scope: global, function, and block
- [ ] Higher-order functions (passing functions as arguments)
- [ ] Closures

## Phase 5: Collections
- [ ] Arrays: creating, indexing, and length
- [ ] Common array methods: `push`, `pop`, `shift`, `unshift`, `slice`, `splice`, `indexOf`, `includes`
- [ ] Iterating arrays with loops and `forEach`
- [ ] Transforming arrays with `map`, `filter`, and `reduce`
- [ ] Objects: key-value pairs, dot and bracket access
- [ ] Iterating objects with `for...in` and `Object.keys`
- [ ] Nested arrays and objects

## Phase 6: Working with strings and numbers in depth
- [ ] Common string methods: `slice`, `substring`, `split`, `replace`, `trim`, `includes`
- [ ] `Math` object: `Math.floor()`, `Math.ceil()`, and more
- [ ] `Number` object: `Number.isInteger()` and more
- [ ] Type conversion: `Number()`, `String()`, `parseInt`, `parseFloat`
- [ ] Equality and coercion pitfalls

## Phase 7: Errors and debugging
- [ ] Reading error messages and stack traces
- [ ] `try...catch`
- [ ] Throwing errors
- [ ] Debugging with `console` methods and browser DevTools breakpoints

## Phase 8: Objects and structure
- [ ] Object methods and `this`
- [ ] Constructor functions and `class` syntax
- [ ] Modules: `import` and `export`
- [ ] Organizing code across files

## Phase 9: Asynchronous JavaScript
- [ ] The event loop and call stack (concept)
- [ ] Callbacks
- [ ] Promises: `.then`, `.catch`
- [ ] `async` and `await`
- [ ] `fetch` and working with JSON

## Phase 10: Working with the environment
- [ ] The DOM: selecting and changing elements
- [ ] Events and event listeners
- [ ] Browser storage basics (`localStorage`)
- [ ] Running JavaScript in Node.js

## Phase 11: Building projects
- [ ] Small command-line programs
- [ ] A small interactive browser project
- [ ] Reading and writing data from a file or API
- [ ] Testing basics
