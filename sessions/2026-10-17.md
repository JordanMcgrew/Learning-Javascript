## Understanding checks and corrections (useful for tutoring)
- Properties vs methods: Jordan restated that properties have no `()` and methods always do, with input optional per method. Confirmed. Refinement: a property is a stored characteristic of a value that you read (not "call"); a method is a shared action applied to a value.
- Instances: methods connect to a data type, and a value like `"hello"` is an instance of the string type. Confirmed.
- `.length` is a property, not a method. `console.log()` is a method on the `console` object, not on a data type.
- `Math.floor()` and `Number.isInteger()` are called on the `Math` or `Number` object, with the value passed in. They are not called on the value.
- `const`: cannot be reassigned, must be given a value when declared. `var` and `let` allow reassignment. Jordan reasoned this correctly. Refinement: "need to be `let`" is more precisely "cannot be `const`"; `const` also does not freeze the contents of objects or arrays.
- `dog++` then `dog--` from `1` gave `2` then `1`. Correct.
